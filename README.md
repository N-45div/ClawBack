# ClawBack

**Spare change in, real investments out.**

ClawBack rounds up your everyday payments into savings you can always withdraw. Every $0.50 you save earns a play on an arcade claw machine whose prizes are slices of real assets. You never wager money: your savings are never at risk.

Built for **Solana Blitz v10** (MagicBlock), track: *Entertainment Finance for Everyone*.

> Work in progress. Full README with architecture, demo video and run instructions lands on Day 3. See [PLAN.md](PLAN.md).

- `app/`: React + Vite frontend (demo mode works offline)
- `programs/clawback/`: Anchor program using MagicBlock Ephemeral Rollups + VRF
